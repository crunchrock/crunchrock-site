Making Unity talk to a light gun

Sole Unity developer. Dec 2024 – Apr 2025. Serial protocol.

We inherited a half-built shooting trainer. On day one the Unity client was receiving a packet from the gun and had no idea how to read it. We rewrote the controller classes against the packet the hardware actually sends, built a loopback rig so it could be tested without the gun in hand, then wrote the calibration that maps physical aim to screen space.

Shipped. A calibrated hardware trainer with the protocol tested end to end.

Owning features on a Unity 6 web game

Plobie / Plantdex. Dec 2025 – Mar 2026. Unity 6.3, WebGL.

We weren't handed tickets, we were handed features and asked to come back when they worked. Quest flow, the garden interaction layer and progression UI, plus the WebGL optimisation that keeps a foliage-heavy isometric scene inside a browser's memory ceiling.

Shipped. Whole features owned start to finish on the current Unity LTS.

Making a hundred enemies die readably

ASSC. Apr – Aug 2025. Unity, URP, VFX.

The hard part of a horde isn't spawning it — it's making a hundred simultaneous deaths legible enough that the player still knows what they hit. Spray and impact cues that survive being stacked forty deep, tuned against frame budget rather than against a still frame.

Shipped. Effects that read at crowd scale without the frame time going with them.
